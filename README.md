# Ecommerce API com Flask

API de Ecommerce desenvolvida com Flask. Este projeto fornece endpoints para gerenciar produtos, pedidos e autenticação de usuários.

---

## **Funcionalidades**
- Autenticação de usuários com JWT.
- CRUD de produtos.
- Gerenciamento de pedidos.
- Suporte a migrações de banco de dados com Flask-Migrate.

---

## **Pré-requisitos**
Certifique-se de ter instalado:
- Python 3.8 ou superior
- Virtualenv (opcional, mas recomendado)
